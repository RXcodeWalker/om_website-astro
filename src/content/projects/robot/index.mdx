The robot follows a black line using an IR sensor, navigating a path autonomously. When the ultrasonic sensors detect an obstacle ahead, a servo motor activates a flap that pushes the object out of the way. A companion app provides manual override — direct control over movement when autonomous navigation is not the goal.

The interesting part was integrating the three control modes (autonomous line-following, obstacle clearance, manual override) without them interfering with each other. Built and tested at an IIT makerspace.
